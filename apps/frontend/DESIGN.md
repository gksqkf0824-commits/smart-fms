# 프론트 디자인 기준

쏘카(socar.kr)의 방식을 바탕으로 했다: Pretendard, 흰 바탕, 청회색 무채색, 그림자 없이 1px 테두리만 있는 패널, 파랑은 누를 수 있는 것에만, 대화체 제목.
그 위에 evida만의 요소 네 가지를 더했다.

## evida만의 요소

1. **번호판 칩** — 차량은 어디서나 `<Plate>`(흰 바탕, 진한 테두리, `12가 3456`)로 보여 준다.
2. **기준선 있는 오염도 막대** — `<PollutionScale>`은 0~10% 구간에 경고 2%·심각 5% 눈금을 그린다. 판정이 2%·5%에서 갈리므로 0~100% 막대는 쓰지 않는다.
3. **상황을 말하는 제목** — "세차를 기다리는 차량이 2대 있어요"처럼 해요체 문장으로 쓴다. 영문 대문자 라벨, `A · B · C` 식 메타 문자열, `제목 — 부제` 식 라벨은 쓰지 않는다.
4. **움직임은 한 곳** — 고객 반납 분석 중 사진 위를 지나는 스캔선만 움직인다. `prefers-reduced-motion`이면 끈다.

## 토큰 (`src/index.css`)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--ink` / `--ink-2` / `--ink-3` | `#1b2230` / `#4a5667` / `#697383` | 제목·본문 / 보조 글 / 설명 |
| `--line` / `--fill` | `#e5e8ef` / `#f2f3f8` | 패널 테두리 / 빈 막대·비활성 면 |
| `--blue` | `#0a6cff` | 버튼·링크·선택 상태만. 쏘카 `#0078ff`보다 한 단계 진하게 해 흰 바탕 글자 대비 4.5:1 이상 |
| `--go` / `--wash` / `--stop` / `--wait` | 초록 / 주황 / 빨강 / 회색 | 차량 상태·오염 등급만. `.tone-*` 클래스로 적용 |

- 모서리: 번호판 5px < 입력 12px < 패널 16px < 사진 20px
- 숫자는 `.num`(tabular-nums)으로 자릿수를 맞춘다.
- 상태값·등급·기준치·조치 이름은 `src/fleet.js` 한 곳에서 가져다 쓴다. 화면마다 따로 정의하지 않는다.

## 공용 컴포넌트

| 파일 | 내용 |
|---|---|
| `components/ui.jsx` | `Plate`, `StatusTag`, `GradeTag`, `PollutionScale`, `RatioCell`, `Notice`, `Logo`, 아이콘 |
| `components/Inspection.jsx` | `Verdict`(등급·오염 면적·판정 이유), `Detections`, `ActionSteps` — 차량 상세·AI 분석·반납 접수가 같이 씀 |
| `components/VehicleTable.jsx` | 차량 표 (행 전체 클릭, 키보드는 번호판 링크) |
| `components/AppHeader.jsx` | 상단 메뉴 (좁은 화면에서는 메뉴 줄이 가로 스크롤) |

페이지 전용 레이아웃은 `pages/*.css`에 둔다. `main.jsx`에서 `index.css`를 `App`보다 먼저 불러와야 페이지 CSS가 공용 규칙을 덮어쓸 수 있다.
